## Источники и карта
Search Console https://www.smart-lead.org.ua/ (обновление16.10.2026) содержит одну индексированную страницу — главную (обход17.10.2026). Остальные примеры: wp-admin/*, wp-content/plugins/*, ?s={search_term_string}, /search/{search_term_string}/feed/rss2/. Это технические URL без подходящего нового контента; массово на главную не перенаправлять. Старый Sitemap в GSC не отправлялся. HTTP старого origin503, HTTPS неверный сертификат. Архивный CDX не ответил; поиск не дал дополнительных подтверждённых страниц. README проекта подтверждает перенос главной и политики.

| --- | --- | --- |
| / и /index.php без WordPress content/search query | https://smart-lead.pages.dev/ |301 |
| /privacy-policy и /privacy-policy/ | https://smart-lead.pages.dev/privacy-policy/ |301 |

Главная и политика сохраняют query string. У главной исключены имена параметров s,p,page_id,attachment_id,preview,rest_route,feed. Неизвестные адреса не входят в правила; новый сайт и его canonical не менялись.
