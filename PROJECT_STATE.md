# Smart Lead — состояние проекта

Актуализировано: 2026-10-28 по production, main, Cloudflare UI и Google Search Console. Результаты проверок ниже имеют собственную дату.

## Проект и архитектура
Украиноязычный сайт услуг маркетинга Smart Lead. Ручной перенос контента и оформления с WordPress в HTML/CSS/JavaScript без Elementor, jQuery и клиентского фреймворка. Vite 7 собирает две HTML-страницы; Cloudflare Pages обслуживает статику и две Pages Functions. Базы данных в текущем коде нет.

## Источник истины и публикация
- Основной код: https://github.com/dimamarktarg/smart-lead, production-ветка `main`.
- Рабочий checkout в текущем зеркале ChatGPT: `smart-lead-seo/` (корень этого файла). Соседние `smart-lead-work/` и `smart-lead-main/` не являются источником новых изменений.
- Production: https://smart-lead.pages.dev/; проект Cloudflare Pages `smart-lead`.
- Путь: GitHub main → автоматическая сборка `npm run build` → `dist/client`; Pages Functions берутся из `functions/`.
- Использовались тематические ветки/PR и разрешённый прямой push в main. Проверять актуальную защиту ветки; не обходить её.

README описывает перенос, но часть сведений об аналитике и прошлой QA устарела; актуальную реализацию смотреть в указанных файлах.

## Интеграции и поведение
- GitHub: ChatGPT Codex Connector установлен 2026-10-10 на аккаунт владельца с доступом ко всем текущим/будущим репозиториям этого аккаунта. Создание проверочной ветки через connector прошло; ветка удалена. Причина прежнего 403 устранена установкой приложения, а не изменением кода.
- Cloudflare Pages: GitHub-интеграция и автоматические production deployment. 2026-10-25 UI подтвердил production `7dfe038`, success, branch main, build `npm run build`, root `/`, output `/dist/client`. Пользовательских правил `_headers` и `_redirects` нет.
- Telegram: runtime secrets `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` задаются в Cloudflare, значения не хранить в GitHub. `contact.js` валидирует запрос, формат телефона и ID формы; отправляет имя, телефон, вид заявки и время Europe/Kyiv. Успех возвращается после подтверждения Telegram API.
- GA4: публичный measurement ID `G-WW8K4HSBZY`. `app.js` отправляет `form_start`, `generate_lead` после успешного API-ответа, `form_submit_error`; `analytics.js` — `contact_click` для телефона/Telegram. ID форм: 4 consultation, 7 ad_audit, 8 ad_strategy, 9 callback. Значения имени и телефона в параметры этих событий не включены.
- Consent: аналитическое хранилище по умолчанию granted вне списка регионов; для ЕС/ЕЭЗ, GB и CH — denied до выбора. GA-скрипт загружается и в denied-режиме. Баннер определяется через `/api/visitor-region`, прежний выбор хранится в localStorage; при ошибке определения страны баннер показывается. Сохранённый отказ учитывается и вне списка. Рекламное хранилище/персонализация отключены. Это описание кода, не юридическое заключение.
- Search Console: владение `https://smart-lead.pages.dev/` подтверждено HTML-метатегом; 2026-10-25 UI подтверждает статус владельца именно этого ресурса. Не удалять проверочный метатег из index.html.
